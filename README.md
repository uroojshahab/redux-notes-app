# 📝 Redux Notes App

A simple Notes-taking app built with **React** and **Redux Toolkit**, allowing users to add, edit, and delete notes with real-time state management.

---

## 🚀 Features

- Add a new note
- Edit an existing note
- Delete a note
- Conditional rendering when no notes are available
- Global state management using Redux Toolkit

---

## 🧠 What I Learned

While building this app, I learned and applied:

- **React basics** (components, props, state)
- **Event handling** (form submission, button clicks)
- **Conditional rendering** (rendering content based on state)
- **React-Redux integration**
- **Redux Toolkit** for simplified state management
- **useSelector and useDispatch** hooks to interact with the Redux store
- **Structuring Redux logic** using slices (`createSlice`)

---

## 🛠 How Redux Helped

Redux helped me in several ways:

- ✅ **Centralized State**: I was able to manage all notes in a single store, making it easier to share data across components.
- 🔄 **One-Way Data Flow**: Updates to the notes were handled via dispatched actions, keeping the flow predictable and easy to debug.
- ✨ **Separation of Concerns**: Logic for adding, editing, and deleting notes was separated from UI, making the code cleaner and modular.
- 🔧 **Simplified Logic with Redux Toolkit**: Using `createSlice`, I was able to define reducers and actions in one place with minimal boilerplate.

## 📌 How to Run

1. Clone this repository
2. Run `npm install`
3. Run `npm run dev` to start the development server

## ✍️ Final Thoughts

This project helped me understand how Redux can simplify state management in larger apps. Instead of passing props around, I could manage state globally and focus more on building UI components efficiently.

It’s a great foundational app to start learning about **state management in React applications**.
